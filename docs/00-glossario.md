# Glossário

O glossário vem antes dos outros capítulos para que o leitor não precise sair do texto para entender um termo ou uma sigla.

O Quadro 0.1 traz os termos do domínio, e o Quadro 0.2, as siglas usadas na documentação.

Quadro 0.1 — Termos do domínio

| Termo | Significado |
| --- | --- |
| Administrador | Usuário que configura usuários, setores, categorias, roteamento e base de conhecimento |
| Aluno | Usuário que faz as perguntas e é dono dos seus chamados |
| Artigo | Texto da base de conhecimento que o assistente usa para responder |
| Assistente | Parte do One que entende perguntas em linguagem natural e só responde com base nos artigos publicados |
| Atendente | Funcionário que atende os chamados dos setores a que pertence |
| Autoatendimento | Resolução da dúvida pela resposta do assistente, sem atendimento humano; só conta quando o aluno responde "Sim" à pergunta "Isso resolveu?" |
| Base de conhecimento | Conjunto de artigos mantido pela instituição, de onde o assistente tira as respostas |
| Chamado | Pedido rastreável criado a partir de uma conversa que não resolveu a dúvida; para o aluno, aparece como solicitação |
| Conversa | Troca entre o aluno e o assistente, da primeira mensagem até o desfecho |
| Desfecho | Resultado de uma conversa, sempre um só: resolvida pelo autoatendimento, escalada (chamado criado), recusada (o aluno não quis abrir chamado) ou abandonada (sem resposta dentro da janela de inatividade) |
| Encaminhar | Mover o chamado para a fila de outro setor |
| Histórico | Registro de cada passo do chamado, com autor, data e hora; só recebe acréscimos |
| Linha de base | Valores do atendimento atual, informados pela coordenação, usados como referência para comparar o piloto |
| Nota interna | Mensagem do chamado que só atendentes e administradores veem |
| Piloto | Primeiro uso do One com usuários reais, em escala pequena: uma instituição, uma coordenação, os alunos de ADS, até três setores e de dez a trinta artigos |
| Portal do Aluno | Sistema da instituição em que o aluno já resolve serviços como o boleto do semestre e o atestado de escolaridade |
| Representante de turma | Aluno que serve de filtro entre a turma e a coordenação, para que só os assuntos importantes cheguem à coordenadora |
| Resposta pública | Mensagem do chamado que o aluno vê |
| Roteamento | Escolha do setor que recebe o chamado, feita uma única vez, na criação, pela regra da categoria |
| Setor | Unidade da instituição com uma fila própria de chamados, como uma coordenação de curso ou a CAE |
| Setor de triagem | O único setor que recebe os chamados que nenhuma regra de roteamento cobre |

Quadro 0.2 — Siglas

| Sigla | Significado |
| --- | --- |
| ABNT | Associação Brasileira de Normas Técnicas |
| ADS | Análise e Desenvolvimento de Sistemas |
| API | Interface de programação de aplicações |
| AVA | Ambiente virtual de aprendizagem |
| CAE | Central de Atendimento ao Estudante |
| IA | Inteligência artificial |
| INEP | Instituto Nacional de Estudos e Pesquisas Educacionais Anísio Teixeira |
| LGPD | Lei Geral de Proteção de Dados Pessoais |
| MEC | Ministério da Educação |
| MVP | Produto mínimo viável (do inglês *minimum viable product*) |
| PEI | Projeto Extensionista Integrador |
| PWA | Aplicação web progressiva (do inglês *progressive web app*) |
| REST | Estilo de arquitetura para serviços web baseado em recursos e no protocolo HTTP |
| RF | Requisito funcional |
| RNF | Requisito não funcional |
| SLA | Acordo de nível de serviço (do inglês *service level agreement*) |
| SPA | Aplicação de página única (do inglês *single page application*) |
| UC | Caso de uso |
